# Tactile map references

Real-world tactile maps for blind readers, paired where possible with a visual plan of the same building. Use these as ground truth for what deployed tactile maps look like (symbols, braille keys, legends, guide paths) and to compare against bumps output.

## Pairs

**Queen Mary Hospital, Hong Kong** — same site, different granularity:
- `queen-mary-hospital-tactile.jpg` — outdoor pedestal braille + tactile campus plan; legend covers You Are Here, accessible lift, staircase, ramp, escalator, guide path, north line. [Commons](https://commons.wikimedia.org/wiki/File:Queen_Mary_Hospital_Braille_and_Tactile_Floor_Plan.JPG)
- `queen-mary-hospital-visual-plan.jpg` — visual floor plan (fire evacuation plan, Ground Floor Main Block) photographed inside the same hospital. [Commons](https://commons.wikimedia.org/wiki/File:HK_%E9%A6%99%E6%B8%AF%E5%8D%97%E5%8D%80_Southern_District_PFL_Pokfulam_%E8%96%84%E6%89%B6%E6%9E%97%E9%81%93_Pok_Fu_Lam_Road_%E7%91%AA%E9%BA%97%E9%86%AB%E9%99%A2_Queen_Mary_Hospital_floor_plan_sign_April_2024_R12S.jpg)

**Congress Center Hamburg (CCH)** — same floors, tactile vs visual:
- `c3tactile-cch-2nd-floor-printed.jpg` / `c3tactile-cch-3rd-floor-printed.jpg` — tactile venue plans deployed at 39C3 by [c3tactile.org](https://c3tactile.org) (embroidered map surface + 3D-printed braille legend plates: Leitsystem, Wand, Treppe, Aufzug, WC, Du bist hier). Hall letters match the CCH halls (2nd: D/E/F/G/1/Y; 3rd: Saal 1, Saal Zero, Bar). [Commons: 2nd](https://commons.wikimedia.org/wiki/File:C3tactile_2nd_floor_plan_at_39C3.jpg), [3rd](https://commons.wikimedia.org/wiki/File:C3tactile_3rd_floor_plan_at_39C3.jpg)
- `cch-visual-plan-level2.jpg` / `cch-visual-plan-level3.jpg` — official CCH per-floor isometric plans (Floor 2nd, Floor 3rd) from [cch.de](https://www.cch.de/en/planning/spaces-areas/at-a-glance). ⚠️ Copyrighted marketing material — local test reference only, do not redistribute.
